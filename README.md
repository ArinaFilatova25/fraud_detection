# Credit Card Fraud Detection

### Обнаружение мошеннических транзакций с помощью машинного обучения

## О проекте

Проект посвящён разработке и сравнению моделей машинного обучения для выявления мошеннических операций по банковским картам.

**Цель исследования** — построить модель бинарной классификации, способную выявлять мошеннические транзакции, и оценить качество её работы с учётом сильного дисбаланса классов.

Особое внимание уделено сравнению алгоритмов, подбору гиперпараметров, оптимизации порога классификации и анализу ошибок модели.

## Данные

**Источник:** [Credit Card Fraud Detection — Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

Датасет содержит 284 807 транзакций, совершённых за два дня.

- `V1–V28` — анонимизированные признаки, полученные методом PCA.
- `Time` — время в секундах относительно первой транзакции.
- `Amount` — сумма транзакции.
- `Class` — целевая переменная: 0 — обычная транзакция, 1 — мошенническая.

**Главная особенность данных:** только 0,17% транзакций относятся к мошенническим. Поэтому стандартная метрика Accuracy недостаточна для оценки качества моделей.

## Стек технологий

**Язык:** Python

**Библиотеки:**
- Pandas, NumPy — обработка данных.
- Matplotlib, Seaborn — визуализация.
- Scikit-learn — машинное обучение, кросс-валидация и оценка качества.
- LightGBM — градиентный бустинг.

## Этапы исследования

### 1. Исследовательский анализ данных (EDA)

- Изучение структуры датасета.
- Анализ распределения целевой переменной.
- Исследование распределений признаков.
- Логарифмирование признака `Amount`.
- Масштабирование числовых признаков с помощью RobustScaler.
- Разделение данных на обучающую и тестовую выборки с сохранением пропорций классов (70/30).

### 2. Построение моделей

Обучены и сравнены семь алгоритмов:

1. Logistic Regression
2. k-Nearest Neighbors (kNN)
3. Decision Tree
4. Bagging
5. Random Forest
6. Stacking
7. LightGBM (Gradient Boosting)

Для подбора гиперпараметров использовались GridSearchCV и StratifiedKFold с пятью фолдами.

### 3. Оценка качества

Модели сравнивались по следующим метрикам:

- Precision
- Recall
- F1-score
- ROC-AUC
- Accuracy

Дополнительно исследовано влияние порога классификации на F1-score.

### 4. Анализ ошибок

Для выбранной модели проведён анализ:

- False Positive (FP) — обычные транзакции, ошибочно классифицированные как мошеннические.
- False Negative (FN) — мошеннические транзакции, пропущенные моделью.
- Зависимости ошибок от суммы и времени транзакции.

## Основные результаты

**Лучшей моделью по F1-score в проведённом сравнении стала kNN.**

Для выбранной модели на тестовой выборке:

| Показатель | Значение |
|---|---|
| False Positive Rate (FPR) | 0,01% |
| False Negative Rate (FNR) | 27,7% |
| Ложные срабатывания (FP) | 10 |
| Пропущенные мошеннические транзакции (FN) | 41 |

### Интерпретация результатов

- Модель демонстрирует очень низкую долю ложных срабатываний.
- При этом она пропускает около 28% мошеннических транзакций.
- Анализ ошибок показывает, что некоторые мошеннические операции трудно отличить от обычных на основании имеющихся признаков.
- При практическом применении необходимо учитывать баланс между стоимостью ложной блокировки и финансовыми потерями от пропущенного мошенничества.

## Выводы

1. Для задач fraud detection важно учитывать сильный дисбаланс классов.
2. Высокая Accuracy не гарантирует эффективного обнаружения мошенничества.
3. Подбор порога классификации позволяет изменять баланс Precision и Recall.
4. Выбор итоговой модели должен учитывать не только F1-score, но и бизнес-стоимость ошибок.
5. Дальнейшее развитие проекта может включать cost-sensitive learning, методы работы с дисбалансом классов и оценку моделей по PR-AUC.
